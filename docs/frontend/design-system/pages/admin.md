# Super Admin

**Route:** `/admin`  
**Job:** Ops console for wallets, packages, businesses, numbers, and voices.

**Chrome:** Icon rail on `md+`. Bottom tabs below `md`. The link list is `ADMIN_LINKS` (Overview, Wallets, Packages, Businesses, Numbers, Voices). It is not the owner desk list. A nested admin screen hides the phone tabs and shows one control named for the parent admin list. Hits are at least 44px. Focus ring is the brand ribbon. Filled primary is accent fill with an on-fill label.

Do not send an admin session into owner routes, or an owner session into admin routes.
