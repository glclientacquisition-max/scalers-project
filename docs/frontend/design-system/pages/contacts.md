# Contacts

**Route:** `/contacts`  
**Job:** Named callers. Not a CRM.

**Chrome:** Large in-page Contacts title (`deskListTitleClass`). No product wordmark. Search field (`ContactsSearch`, `type="search"`, Name or number) and one primary **Add** sit on the lead row at every width. Add opens DeskDialog options: New (manual `AddContactPanel` form) · CSV (`/contacts/import`) · From this phone (`PhonebookImportButton` / Contact Picker, hidden when the picker is unavailable). No standalone Import CSV or phonebook CTAs on the lead. Segments are filled pill chips (`InboxFilterPills`, `aria-label` Filter contacts): All · Saved · Unsaved (`saved=` query). Same chip DESIGN as the Inbox purpose row (solid active `#005CCC`, muted idle, `min-h-11`, snap scroll, trailing fade, count badge only when a real count is already loaded). Nouns stay All · Saved · Unsaved. Purpose piles (Needs you / Visits / Holds / …) stay Inbox-only. Sort is a second underline `FilterTabs` row (`aria-label` Sort contacts): Last call · Name, same family as Inbox List/Work. Nested contact files and import do not render Contacts as a page title.

**One family:** Phone (`< md`) is the list row. `md+` is one table. `lg+` is the same table with a Phone column. No third card layout. Hits stay `min-h-11` / `deskHitClass` (`h-12 w-12`). Phone `main` already clears `--desk-tabbar-clearance` (tab bar plus safe area).

**Segments:** All · Saved · Unsaved only. Pill chips, not underline FilterTabs. No Recent tab. No nested DeskBack for those piles. No Invite Friends. No slider skin. No Inbox purpose nouns.

**Row:** Same recipe as Inbox. Avatar, name, one factual subline (`contactListSubline`: Unsaved, phone, or last call). Last call time sits with the timestamp, never "last seen" or "active now". Tap the row to open `/contacts/[id]` with the list segment on the URL (`from=contacts`). No Open column. Phone column from `lg`. If a phone exists, Call + WhatsApp sit in the trailing `deskHitClass` dock (`CallLink` `tel:` + `WhatsAppLink` `wa.me`, opened only). No `callId`. No `lead_status` write-back. No delivered claims. No Online, last seen, presence dots, or live badges. Hangup Want and the four-block summary live on the person file and the call.

**Ticket strip:** `/calls/[id]` header uses `ContactStrip` in this same family (avatar, one fact, Call + WhatsApp). Allowed facts: Unsaved, phone, last call, call/WA opened stamp. Reach is `opened` only (`tel:` / `wa.me`). No `lead_status` or Needs you invent. No Meta theater. List Phase 1 chrome stays on `/contacts`. Do not restyle the list to match the ticket, or the ticket to invent a second row language.

**Detail:** `/contacts/[id]`. Name (or **Name this caller**). Phone stays locked. Phone, last-call fact if known (`contactLastCallFact`, never last seen). Honest KPI strip (`ContactKpiStrip`) under the name: one flex row of sourced cards only. **Interactions** = assembled ticket/call rows for that contact. **Visits done** = jobs with status `done`. **Customer since** = relative months from earliest first-seen / first call / `created_at`. Hide when unknown or the count is 0. No wallpaper numbers. No glass. Notes left. History right. Phone is the list row. `md+` is the table. No `min-w-[560px]` floor. History rows are Inbox tickets for this contact (`assembleInboxItems` + `itemSignalLabel`). Stamps are Inbox states only (Answered, Visit done, Hold, Human asked, Missed, Live). Invent no Call / Request CRM types. Tap a History row that has a call (`inboxRecordHref`) to open the conversation. No Call column. If a phone exists, Call + WhatsApp sit as top `deskHitClass` icons in the header (`ContactActionDock`: `CallLink` `tel:` + `WhatsAppLink` `wa.me`). No labeled Call / WhatsApp pills under the name. Bare-profile WhatsApp is `wa.me` only. No `callId`, no `lead_status` write-back. Name edit is always on the file (`ContactNameForm`, `updateContactName`). Empty or junk name shows **Name this caller** plus Save. Saved name shows **Name** plus Save. After Save the file is Saved and the route stays. If a phone exists, **Inbox threads** opens Inbox with existing search (`inboxThreadsFromContactHref`: `purpose=all` and `q` = phone). No phone: no Inbox threads control. History What is one truncated line (`deskPreviewClass`); tap the cell to expand detail. `DeskBack` is an icon-only chevron. `aria-label` is Contacts, or Call when opened from a conversation, or Inbox from a pile. Back from the list restores `/contacts` with `saved`, `sort`, `q`, and `page` preserved (segment preserved). Tap identity on a ticket `ContactStrip` opens this file.

**Do not:** ship a contact activity strip on the list. Invent Online, last seen, presence dots, or active now. Add Invite Friends. Write `lead_status` from the list. Claim delivered from a list tap. Put Inbox purpose nouns on Contacts chips. Ship VIP / Lead / Cold / SEGMENT. Fake KPI counts.

Identity is tenant + E.164 phone. The fifth call from the same number is the same contact. Last call on the list is the newest call or work stamp. Last reason on the person file is the same hangup one-liner Inbox uses for that call. The Want card on the person file is the four-block summary, not the list line.
