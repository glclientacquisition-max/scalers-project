# Ticket in-chat display polish — Product ACCEPT

**Date:** 2026-09-21  
**Status:** ACCEPT — founder ask via Chief  
**Ladder:** Parallel desk polish. Not Funnel. Not WA Cloud connect. Not Contacts (Phase 1 + strip closed).

---

## Problem

Call ticket transcript/timeline chrome feels scattered — too many competing lines, chips, and wrappers around the conversation. Owner loses the thread. Action dock (WhatsApp · Call · Ping · Mark done) must stay reachable.

## Operator outcome

On call/ticket detail, the conversation reads as **one clear chat/timeline**: who said what, when it matters. Chrome is quiet. Thumb dock stays put and honest.

## Acceptance

1. **Keep:** Action dock / buttons — Mark done · WhatsApp · Call · Ping teammate (and Confirm / Hold Done when that ticket recipe requires). ≥44px, safe-area, same honesty as #360/#369 (opened ≠ delivered; no Rings theater).  
2. **Declutter transcript/timeline:** Remove visual scatter — excess borders, duplicate meta, redundant stamps, noisy system lines that don’t change the next action. Prefer one vertical conversation stream.  
3. **Keep honest signals only:** Delivery/escalation chips stay if Critic-true (channel + time or failed). Drop decorative chrome that isn’t a fact.  
4. **Contact strip:** Leave as shipped (#383) — don’t restyle into a second language.  
5. **Responsive:** One composition family at ~390 / tablet / desktop.  
6. **No semantics invent:** No new `lead_status`, Needs you rules, or notify channels.  
7. Release smoke at three widths; Critic if any copy could claim sent/rang/Online falsely.

## Out of scope

- Tenant Funnel Page  
- WA Cloud / Meta connect  
- Contacts list or strip redesign  
- Bookings honesty K1–K4 reopen  
- Voice brain / PSTN transfer  
- New dock verbs beyond existing recipes

If dock is buried, honesty chips become soft-sent/Rings theater, or a second visual language appears → revert. Prefer revert over patching clutter with more chrome.
