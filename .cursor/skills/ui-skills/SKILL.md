# UI Skills (Scalers)

Source: [ibelick/ui-skills](https://github.com/ibelick/ui-skills) (MIT). Router kept. Remote taste packs left out.

Product: a calm Kenya desk. WhatsApp-class density. Navy ink, ribbon `#0096FF`, primary fill `#005CCC` with a white label.

## Before any catalog

1. Read `docs/frontend/FRONTEND_CONSTITUTION.md` and `docs/frontend/design-system/MASTER.md`.
2. Stay in Desk paths (`docs/agents/DESK_UX.md`).
3. Copy: `/no-ai-slop`. Motion: `/desk-motion` only (pending, live, land, shift, press).

Do not run `npx ui-skills get` to pull impeccable, frontend-design, shadcn themes, GSAP, Lottie, or a second `DESIGN.md`. Those fight the constitution.

## Pick one

Prefer 1. Use 2 only when the task has two clear angles. Never more than 3.

| Task | Skill |
| --- | --- |
| Fast polish: spacing, type, density, AI chrome | `/baseline-ui` |
| Audit one surface against constitution. No drive-by rewrite | `/improve-ui` |
| Names, keyboard, focus, forms, 44px hits | `/fixing-accessibility` |
| Prove the running page | `/reticle` |
| Desk copy or empty-state strings | `/no-ai-slop` |
| Any movement | `/desk-motion` |

If the goal is unclear, ask one short question.

## Refuse

MUI, shadcn theme, Instagram chrome, purple or cream-serif-terracotta defaults, Inter as a new face, glass, mesh, nested cards for a table job, a second list layout for the same dataset, hover-only actions, hits under 44px, em dashes in UI strings.

`create-design-md` and `fixing-motion-performance` from upstream stay out. MASTER and desk-motion already own those jobs.
